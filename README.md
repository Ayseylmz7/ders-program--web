# 📚 Web Programlama 1 - Ders Paneli

Bu depo, **Web Programlama 1** dersi kapsamında geliştirilen HTML5 ve CSS3 tabanlı örnek bir hafta içi ders programı ve içerik yönetim paneli uygulamasını içermektedir.

## 🚀 Proje Hakkında
Proje, web geliştirmenin temellerini pekiştirmek amacıyla tasarlanmıştır. Saf HTML yapısı ve satır içi (inline) stiller kullanılarak özelleştirilmiş bir arayüze sahiptir.

### 🛠️ Kullanılan Teknolojiler ve Özellikler
* **HTML5:** Anlamsal etiketler (`<figure>`, `<figcaption>`), tablo yapıları (`rowspan`, `colspan`), sayfa içi bağlantılar ve HTML entities.
* **CSS3 (Inline Styles):** Özel renk paleti (Lavender/Bordo tonları), tipografi ve düzen ayarları.
* **Medya:** Görsel ve ikon entegrasyonları.
